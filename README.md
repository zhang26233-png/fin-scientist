# FinScientist

FinScientist is a minimal local Streamlit app for generating a simulated stock research summary.

## Setup

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

## Run

```powershell
streamlit run app.py
```

Open the local URL shown by Streamlit in your browser.

## Notes

This version does not call any real market data or AI APIs. The research summary is simulated locally.
