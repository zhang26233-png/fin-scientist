# Screening Module Specification

## 1. 模块定位

自动研究对象筛选模块用于输出研究候选池，不是买入建议。

模块目标是帮助用户从一组股票中完成初筛，找到更值得进一步研究的对象。筛选结果只代表研究优先级，不代表买入、卖出、持有建议，也不承诺收益。

## 2. 用户输入

- 市场选择：A股 / 港股 / 美股
- 股票池选择：默认股票池 / 自定义股票池
- 多股票代码输入
- Top N 筛选数量

## 4. 指标计算

计划计算以下指标：

- 最新价格
- 近 5 日涨跌幅
- 近 20 日涨跌幅
- 近 60 日涨跌幅
- MA20
- MA60
- 当前价格是否高于 MA20
- 当前价格是否高于 MA60
- MA20 是否高于 MA60
- 成交量放大倍数
- 年化波动率
- 最大回撤
- 有效交易日数量
- 数据质量结论

## 5. 研究优先级评分

评分原则：

- 使用可解释规则。
- 不使用黑箱机器学习。
- 不命名为买入评分或推荐评分。
- 只代表研究优先级。
- 分数应能追溯到具体指标和规则。
- 数据不足时应降低评分可信度或提示无法评分。

评分不得被解释为买入、卖出、持有建议。

## 6. 入选理由

入选理由必须基于真实指标生成。

示例理由可以包括：

- 近 20 日或近 60 日相对表现较强。
- 当前价格高于 MA20 或 MA60。
- MA20 高于 MA60，趋势结构较强。
- 成交量较过去均值有所放大。
- 数据质量较完整，具备进一步研究基础。

不得使用无法追溯到指标的主观判断。

## 7. 风险提示

结果必须提示以下风险：

- 追高风险
- 波动风险
- 回撤风险
- 数据不足风险
- 数据源风险

风险提示应根据具体指标生成。例如最大回撤较大时提示回撤风险，年化波动率较高时提示波动风险。

## 8. 结果展示

表格字段：

- 排名
- 股票代码
- 股票名称
- 市场
- 最新价格
- 涨跌幅
- 成交量放大倍数
- 最大回撤
- 年化波动率
- 研究优先级评分
- 入选理由
- 风险提示
- 数据源
- 最新交易日

## 9. 错误处理

需要处理以下情况：

- 空输入
- 代码格式错误
- 数据获取失败
- 数据为空
- 数据不足
- 字段缺失
- 网络或接口不可用
- 所有股票都失败

错误处理原则：

- 单只股票失败不能影响其他股票。
- 所有股票失败时应显示清晰提示。
- 页面不能崩溃。
- 不应输出误导性评分。
- 数据不足时应显示“数据不足”或降低可信度说明。
