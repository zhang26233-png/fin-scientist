# Test Checklist

## 1. 启动检查

- Streamlit 是否能启动
- 页面是否能打开
- 控制台是否无明显报错

## 2. 原有功能检查

- 单股查询是否保留
- 多市场选择是否可用
- 数据质量报告是否可查看
- 多股票对比是否保留
- 回测模块是否没有被破坏

## 3. 自动筛选模块检查

- 默认股票池是否能解析
- 自定义股票池是否能解析
- 错误输入是否会崩溃
- 数据失败时是否有友好提示

## 4. 安全文案检查

- 页面是否显示风险提示
- 是否明确不构成投资建议
- 是否没有出现“推荐买入”“必涨”“强烈看多”等表达

## 5. Git 检查

- `git status`
- `git add`
- `git commit`
- `git push`
