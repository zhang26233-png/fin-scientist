# Project Brief

## 项目名称

FinScientist

## 项目目标

构建一个个人金融研究工作台，帮助用户完成行情观察、数据质量检查、技术指标分析、基本面观察、事件分析、回测学习和研究候选池筛选。

## 使用场景

- 学习金融数据分析
- 练习 Python / Streamlit / Codex 项目开发
- 辅助整理研究对象
- 对比不同市场标的
- 搭建个人投研工作流原型

## 当前阶段

项目仍处于学习型原型阶段，不是正式投研系统，不适合直接用于实盘交易。

## 安全边界

- 不构成投资建议
- 不输出交易指令
- 不接入真实账户
- 不做自动交易
- 数据可能延迟、缺失或存在误差
